# SmartBank Pro 🏦

A C++ OOP banking management system built using classes, objects, and vectors.

## Features
- Create new account
- Show all accounts
- Search account by number
- Deposit money
- Withdraw money
- Menu-driven console system

## Technologies Used
- C++
- OOP
- VS Code
- MinGW g++

## Files
- `main.cpp`
- `Account.h`
- `Account.cpp`

## How to Run

```bash
g++ main.cpp Account.cpp -o bank
.\bank.exe
